# 重建目标：完整机器人操作场景

输入是同一真实工作空间的图片序列。输出应覆盖桌面/支撑面、背景/固定障碍、
所有任务相关物体、机器人及其共同坐标系下的布局。独立物体资产只是完整场景
中的组成部分，不能替代整场景重建。

**当前状态：完整高保真场景重建尚未完成。已有图集是单物体/子模块实验。**
本次新增的是保持完整画幅的输入准备、场景实例清单和范围检查，并非新的
重建算法、自动分割或已验证的交互环境。

## 一个具体的操作场景

假设照片中有桌子、瓶子、杯子、托盘、柜子和机械臂。正确输出必须保留它们
原本的相对位置和尺度：机械臂推动瓶子时，瓶子移动，桌面保持不动；瓶子不能
既作为独立物体移动，又在静态背景中留下一个重复影像或隐藏的碰撞体。

| 场景部分 | 外观 | 几何/交互要求 |
|---|---|---|
| 桌面、地面、墙面、固定背景 | 全场景多视角重建的一部分 | 支撑面、边界、固定碰撞体 |
| 瓶子、杯子、托盘、障碍物 | 可独立变换的实例外观 | 各自碰撞体、初始姿态、质量与接触参数 |
| 抽屉、柜门等 | 对应关节运动的部件外观 | 部件坐标、关节轴、限位与阻尼 |
| 机器人、夹爪、工具 | 对齐到真实画面中的机器人外观 | URDF/MJCF、基座位置、关节和执行器响应 |
| 原始布局 | 统一坐标系内的相对关系 | 米制尺度、支撑、遮挡、接触和可达性 |

这是一套组合起来运行的场景。可以分开训练/处理各层，但不能把它们的尺度、
布局和可见性关系丢掉，也不能把所有像素固定成不可移动的整块背景。

## 正确的处理顺序

1. **保留整段、完整画幅。** 先使用相机观察整个静止工作空间的多视角照片。
   场景可以包含许多物体。不得先裁成单个物体再宣称重建了全场景。
2. **建立共同坐标系。** 恢复/读取相机内外参，独立确定尺度，对齐桌面和机器人
   基座。缺失位姿不能用单位矩阵代替。单物体转台照片不等于静止整场景扫描。
3. **重建全场景外观与几何。** 外观采用保留细节的完整训练后端；几何来自多视角
   或已配准深度，单独测量接触区域。已有的小型 CPU 高斯实验不能作为质量标准。
4. **做实例和部件拆分。** 将可操作物体、关节物体和机器人识别为独立实例，
   保留其相对于全局坐标的变换。未分类区域继续保留，不能变成白背景。
5. **组成可交互环境。** 静态层去掉动态实例的重复外观和碰撞几何；为实例连接
   可移动/可关节运动的视觉与物理资产。物体离开后暴露的区域需要已有观测支持，
   未见区域只能标为未知或另采数据，生成式补全不能当作测量真值。
6. **恢复原布局并验证任务。** 先复现实际布局，再生成任务变化。先检查稳定性、
   机器人可达性与接触，再执行冻结策略的真实/仿真成对测评。

手机扫描阶段，机器人可以停在固定姿态；为了观察其后方和下方，可能还需要
补充视角或另一次扫描。若直接使用机器人正在操作的视频，则必须分离相机运动、
机器人运动和物体运动。当前新增入口会记录这种动态序列，但不会把它静默融合
成一个静态场景。

## 新的完整场景输入入口

复制并填写 [workspace_capture_template.json](../examples/workspace_capture_template.json)，
将帧路径换成实际完整照片。模板中的物体清单仅为格式示例，不是自动检测结果。

```sh
python prepare_workspace.py --config my_workspace.json --out outputs/workspace_input
```

该命令实际做的事：

- 原样复制完整图像，检查重复帧和拟合/测试划分；不裁剪、不缩图、不抹白背景。
- 保留每帧相机参数；未知的位姿保持未知。
- 接收可选完整画幅的实例标签图和配准深度；标签 0 表示未分类，仍保留原始像素。
- 保存实例角色、原始变换、支撑关系，以及分开的外观资产/碰撞资产标识。
- 输出 `capture.json`、`scene_graph.json`、`workspace_report.json`。
- 只有已声明静止场景且相机参数完整时，才输出现有后端可以读取的 `scene.json`。
  已知米制尺度和场景边界后才报告 RGB 稠密重建输入就绪；高斯训练仍需要来自
  拟合数据的初始点。此入口本身不估计深度、不恢复相机、不训练高斯。

无位姿图片可以先入库，但完整相机恢复仍是待完成的阶段。声明“静止”只是元数据，
也需要多视角一致性等证据验证。已有实例位置被原样保存，不因入库而自动认证。

## 用什么检查完整性与质量

| 检查层 | 需要的证据 |
|---|---|
| 全场景覆盖 | 桌面、背景、任务相关物体都在范围内；逐实例记录未见区域 |
| 外观 | 全画幅留出视角 + 逐物体区域指标；检查文字、边缘、反光、遮挡及时间连续性 |
| 几何 | 米制尺度、接触面独立测量、孔洞/缺失面、物体底部与支撑关系 |
| 可交互性 | 单独移动一个物体，其他物体/背景不随动；静态层无重复外观与重复碰撞体 |
| 机器人 | 基座、工具、运动学、控制延迟、执行器与接触响应分别校准 |
| 测评替代 | 同任务条件下的真实/仿真闭环试验、成功率误差、误判风险与策略排序 |

尚未完成的自动实例分割、全场景高保真训练、背景去重与填补观测、物理装配、
真实闭环验证必须继续列为待完成，不能因为输入格式通过检查就改成“完成”。
