# Evidence Real2Sim 中文说明

这是一个根据输入数据选择可用路径的研究原型，目的是逐步降低机器人真机测评
成本。**目前没有证明这套仿真可以替代真机测评，也没有宣称任意手机照片都能
生成高质量、物理一致的环境。**

新增并实际运行的模块：

- 可训练的各向异性 3D 高斯参考后端：中心、旋转、尺度、不透明度和颜色都参与
  优化；CPU 可运行。另有尚未在本机运行的 gsplat/CUDA 路径。
- 通用标定图像接口：RGB 多视角估深与稠密 TSDF；有 RGB-D 时直接融合注册深度。
- 完整执行器驱动的机器人/物体动力学：同一时刻相互作用，策略读取当前状态后
  再行动。已有三自由度夹具例子和七自由度 Panda 适配。
- 九类可运行输入例子、模型/数据校验、独立误差和成对评测数据契约。

“通用”在这里指不写死某一物体类别的输入接口和数值算法，不代表对任意材质、
遮挡、透明物体或拍摄方式都保证成功。CPU 高斯参考实现只有固定数量高斯与
SH0 颜色，不含生产级自适应增密。未经标定和独立表面验证，不能认证接触几何。

请先阅读 [不同输入例子](INPUT_CASES.md) 和 [实际验证记录](../reports/VALIDATION.md)。
安装和命令见根目录 README。所有例子只读写本地文件，不向真实机器人发动作。

完整真机替代结论仍需要：目标机器人/工具/表面的一致模型、可靠测量、冻结的
多个策略、同任务条件下的真实与仿真闭环试验、预先确定的任务相关验收标准。
公开论文的结果只能作背景，不能给本项目的新资产背书。
