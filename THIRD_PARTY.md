# Third-party software and data

The source code in this repository is released under MIT. Dependencies retain
their own licenses. No third-party robot meshes, YCB photographs, DROID episodes,
policy checkpoints or pretrained Gaussian models are distributed here.

Dependencies include NumPy, SciPy, PyTorch, OpenCV, MuJoCo, trimesh, h5py, PyArrow,
scikit-image and optional pycolmap / gsplat. Install these from their official
registries and review their licenses when redistributing a combined product.

Algorithms and project references:

- 3D Gaussian Splatting: https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/
- gsplat (optional CUDA rasterization): https://github.com/nerfstudio-project/gsplat
- COLMAP / pycolmap: https://github.com/colmap/colmap
- MuJoCo: https://github.com/google-deepmind/mujoco
- YCB: https://www.ycbbenchmarks.com/object-models/
- DROID: https://droid-dataset.github.io/
- SIMPLER: https://github.com/simpler-env/SimplerEnv
- Real-to-Sim Policy Eval: https://github.com/kywind/real2sim-eval
- RoboSnap: https://github.com/robosnap/robosnap

The CPU Gaussian renderer, plane-sweep/TSDF routines and evaluation adapters here
are compact reference implementations. They are not advertised as exact
reproductions of the above projects. Upstream author results are never counted
as validation of this repository's newly reconstructed assets or policies.

The procedural fixtures generated by `make_demo_data.py`, `make_vision_example.py`
and `make_feedback_example.py` are synthetic examples for this repository.
`scripts/prepare_ycb_local.py` requires an independently acquired local YCB
experiment; it does not download or redistribute the source dataset.
